## 🎯 About me

I'm working toward a career in cybersecurity, covering **both sides of the fence** — attacking systems to understand them, and defending them because I've had to secure my own. I learn by doing: TryHackMe rooms, a home lab I built and maintain myself, and tools I write from scratch rather than just running other people's.

- 🔴 **Offensive:** penetration testing, red teaming, exploit/tool development, and working toward **bug bounty** hunting
- 🔵 **Defensive (learning):** blue teaming, **SOC analyst** skills — detection, monitoring, and incident response, largely through my home lab
- 🤖 **AI (where I'm headed):** **AI security** and **AI research** — adversarial attacks, model security, and using AI in offensive/defensive tooling
- 🛠️ **Builder:** I write my own security tools in Python (see MUDO & NETWORK_DEMON below)
